### Описание
Программа на языке C, демонстрирующая построение линейных программ с использованием математических функций стандартной библиотеки (`sin`, `cos`, `pow`, `sqrt`, `log10`, `fabs`):

* **Задание 1:** вычисление синуса угла, заданного в градусах (перевод в радианы, вывод с точностью до 6 знаков, проверка на значениях 30, 60 и 90 градусов).
* **Задание 2:** вычисление функции варианта 9: $y = b^2 + \sqrt{|a|}$, где $b = \lg|kx|$, $a = (k + x)^3$, $k = 7$.
* **Задание 3\*:** проверка условий для целых частей чисел a, b, y: только одно из чисел A и B чётное, каждое из чисел A, B, C кратно трём.
* **Домашнее задание 5.2:** вычисление выражения: $y = \frac{\cos(2x)}{\pi + 3x} - 8x \cdot \sin(xy) + 5$.
